## Offer

- **Buyer:** an n8n agency or freelancer preparing a client delivery, major update, or workflow takeover.
- **Paid pilot:** EUR 89.
- **Scope:** one baseline and one release candidate, with up to 30 active nodes in the candidate.
- **Deliverable:** changed nodes, connections, external domains, credential types, approval and key reliability boundaries; up to five prioritised release blockers; a client-ready Markdown or print record tied to the checked files by SHA-256.
- **Delivery:** within 48 hours.
- **Not included:** a call, recheck, workflow development or repair, live debugging, infrastructure or RBAC review, penetration testing, compliance certification, or a security guarantee.

Workflow files stay on the customer's device. Only the local report or screen the customer chooses to share is reviewed. Never request production credentials, secrets, customer payloads, or production access.

## Fiverr description

Before you hand an n8n workflow to a client, I will review the release candidate against the previous export and turn the changes into a handoff record. You run the local checker on your own device, so the workflow file, credentials, prompts, and production data stay with you. I review only the report or screen you choose to share.

You receive up to five prioritised release blockers and a change summary covering nodes, connections, external domains, credential types, approval boundaries, and key reliability controls. The client-ready Markdown or printable record is tied to the checked files by SHA-256.

This is a bounded static release review, not live penetration testing or workflow repair.

1. n8n version and deployment type.
2. The locally generated baseline and candidate reports.
3. The intended business action of the workflow.
4. Approved external systems and domains.
5. Expected human approval points.
6. Sanitised acceptance criteria or known failure notes.
7. The handoff deadline and client-facing project name.

Do not attach a raw workflow, credential, API key, cookie, production payload, or customer record.

## FAQ

**Do I need to send the workflow JSON?**

No. You run the checker on your own device. I work from the generated report or screen you choose to share.

**Will you fix the workflow?**

No. I identify and explain release blockers. Workflow development and repair are outside this pilot.

**Does this replace n8n's own audit or workflow diff?**

No. It adds an independent interpretation of changed trust boundaries, external targets, credentials, approvals, and failure controls.

**Do you need production access or credentials?**

No. I do not request production secrets, credentials, or unauthorised live access.

**Does a passing report prove the workflow is secure?**

No. It is a bounded static release review and handoff record, not a penetration test, compliance result, or security guarantee.

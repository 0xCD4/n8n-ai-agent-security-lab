EUR 99 for the first three reviews.

## Included

- one exported n8n workflow with up to 40 active nodes
- local static scan
- manual review of the five highest-risk paths
- Markdown or PDF report
- 30-minute handoff call
- one retest after fixes
- delivery within three working days

## What I review

- webhook authentication and untrusted inputs
- input-to-model and model-to-action paths
- structured output and prompt boundaries
- approval points for external actions
- outbound destinations and tool permissions
- timeouts, retries, logging and error handling

## What to send

Export the workflow after removing production data. Do not send passwords, API keys, OAuth tokens, cookies or customer records. Include a short description of what the automation should do and which nodes can change external systems.

## Boundary

This is a defensive static and configuration review. It is not a penetration test, compliance certification or security guarantee. Production systems are not attacked or changed.
